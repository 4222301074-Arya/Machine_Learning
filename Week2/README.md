# Week 2 - OOP dan Dasar Python

Repository ini berisi materi praktik Week 2 untuk mata kuliah Machine Learning. Fokus utama adalah menguatkan konsep pemrograman Python dasar, paradigma berorientasi objek (OOP), dan prinsip OOP.

## Isi Materi

- `Hands_On_Function_in_Python.ipynb`
  - Latihan dasar fungsi Python: definisi fungsi, argumen, nilai kembali, dan pemanggilan fungsi.
- `Week2_Tipe_Data.ipynb`
  - Pembahasan tipe data dasar Python: string, angka, boolean, list, tuple, set, dictionary, serta operasi dasar pada tipe data tersebut.
- `Hands_On_Main_Principles_of_OOP.ipynb`
  - Konsep utama OOP: kelas, objek, enkapsulasi, pewarisan, dan polimorfisme.
- `Hands_On_OOP_Paradigm_Concepts.ipynb`
  - Praktik paradigma OOP: pembuatan kelas, konstruktor, atribut, metode, dan penggunaan objek dalam pemrograman Python.

## Tujuan Pembelajaran

Setelah menyelesaikan materi Week 2, diharapkan mahasiswa dapat:

- Menulis fungsi Python yang sederhana dan memahami alur eksekusi fungsi.
- Menggunakan tipe data dasar Python secara efektif dalam program.
- Memahami dan membedakan konsep OOP seperti kelas, objek, enkapsulasi, pewarisan, dan polimorfisme.
- Membangun kelas Python dan membuat objek untuk memodelkan masalah nyata.

## Cara Menggunakan

1. Buka notebook yang ingin dipelajari di `VS Code` atau `Jupyter Notebook`.
2. Ikuti sel kode secara berurutan, baca penjelasan, dan jalankan setiap contoh.
3. Ubah parameter atau tambahkan kasus baru untuk memperdalam pemahaman.

- Notebook ini cocok untuk praktik mandiri dan revisi konsep OOP serta dasar Python.
- Jika ingin memperluas materi, coba gabungkan konsep fungsi dan OOP dalam satu kasus nyata.
